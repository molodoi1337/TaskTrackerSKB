# Task Tracker SKB

Мобильное Android-приложение для управления задачами и проектами в студенческом конструкторском бюро. Реализовано на **Kotlin + Jetpack Compose** по архитектуре **MVVM**.

## Возможности

### Задачи
- Создание (название, описание, проект, исполнитель, дедлайн, статус)
- Редактирование любых полей и статуса
- Удаление с подтверждением
- Статусы: «Новая», «В работе», «Выполнена»

### Проекты
- Создание, редактирование, удаление, просмотр

### Поиск, фильтрация, сортировка
- Поиск по названию и описанию
- Фильтр по статусу и проекту
- Сортировка: по дате создания / дедлайну / статусу

### Уведомления
- Локальные push-уведомления о приближающихся дедлайнах (за 24 часа), отправляемые периодической задачей `WorkManager`

### Хранение
- Локальная БД на **Room** (SQLite)

## Технологический стек

| Слой | Технологии |
|------|-----------|
| Язык | Kotlin 1.9 |
| UI   | Jetpack Compose, Material 3 |
| Архитектура | MVVM (ViewModel + StateFlow) |
| Навигация | Navigation Compose |
| Хранение | Room 2.6 |
| Фоновые задачи | WorkManager |
| Асинхронность | Kotlin Coroutines / Flow |

## Структура проекта

```
app/src/main/java/com/skb/tasktracker/
├── MainActivity.kt           — единая Activity + NavHost
├── TaskTrackerApp.kt         — Application + DI вручную + planner WorkManager
├── data/
│   ├── entity/               — Task, Project, TaskStatus
│   ├── db/                   — Room (DAO, Database, Converters)
│   └── repository/           — TaskRepository, ProjectRepository
├── ui/
│   ├── theme/                — Material 3 тема
│   ├── navigation/           — определения маршрутов
│   ├── components/           — общие компоненты (StatusChip, фабрика VM)
│   └── screens/
│       ├── tasks/            — список / создание / детали задач
│       └── projects/         — список / создание / редактирование проектов
├── notifications/
│   └── DeadlineWorker.kt     — фоновая проверка дедлайнов
└── util/
    └── DateFormat.kt
```

## Экраны

1. **Список задач** — поиск, фильтрация по статусу/проекту, сортировка, переход к деталям, FAB добавления.
2. **Создание / редактирование задачи** — все поля, выбор проекта (dropdown), DatePicker для дедлайна, выбор статуса.
3. **Детали задачи** — все поля, быстрая смена статуса, удаление, переход к редактированию.
4. **Список проектов** — CRUD проектов.
5. **Создание / редактирование проекта**.

## Сборка

Требуется **Android Studio Hedgehog (2023.1.1)** или новее, **JDK 17**, Android SDK 34.

```bash
# при первом запуске сгенерировать Gradle Wrapper
gradle wrapper --gradle-version 8.7

# затем стандартная сборка
./gradlew assembleDebug
```

APK будет в `app/build/outputs/apk/debug/`.
